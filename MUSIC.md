# Music sources

`DON'T PRESS THAT` streams its background music from the public GitHub repository `Anubhav9/Yellow-Olive`. The selected tracks are listed in that project's README as CC0/public-domain-compatible game music sourced from OpenGameArt.

Tracks currently used:

- `battle_music_2.mp3` — **8 bit Chiptune Encounter Theme** by Shiru8Bit — CC0
- `screen_2_music.mp3` — **Town Theme RPG** by Joth — CC0
- `signal_town_intro_music.mp3` — **Abandoned** by Preston Peak — CC0

The game starts music only after the player interacts with the page, in line with modern browser autoplay rules. The in-game sound button mutes both background music and sound effects.

No third-party game code or graphics were copied into the 100-game deck; the game mechanics and UI implementation in this repository are original.
