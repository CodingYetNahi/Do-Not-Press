Challenge Guide

DON'T PRESS THAT mixes short brain games and mini challenges so each round can demand a different kind of response. Read the instruction first: some challenges reward speed, while others reward patience, memory or precision.

Memory and path challenges

Memory rounds briefly show positions or a sequence and then hide the answer. Follow the Path presents a route across tiles and asks you to reproduce it in order. Harder versions use more tiles and longer sequences.

Patterns and numbers

Pattern challenges test simple logical sequences such as doubling, square numbers, arithmetic progressions or Fibonacci-style patterns. Comparison rounds ask you to identify the largest or smallest value, while ordering rounds include decoys and can reshuffle after each correct choice.

Visual attention

Odd-one-out and counting challenges require careful scanning. Count only the objects requested by the instruction and avoid guessing from the layout. Color-based rounds may ask you to identify a specific target among distractors.

Direction and rotation

Direction games can ask for the matching arrow, the opposite direction or a rotated result. These rounds are designed to test whether you follow the wording rather than react automatically to the most obvious symbol.

Precision and reaction

Reaction challenges may require waiting for a cue before acting. Precision rounds can ask you to stop a moving marker in a narrow target zone, hit a moving object several times, swipe in the correct direction or hold for a specified period.
