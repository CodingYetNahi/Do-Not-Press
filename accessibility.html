Accessibility & Controls

DON'T PRESS THAT is designed to work with touch screens and modern desktop browsers. Challenge instructions are shown before each interaction so players can understand whether the round requires a tap, click, swipe, drag, hold, wait or answer selection.

Touch controls

On phones and tablets, interact directly with the objects shown in the play area. Swipe challenges require a deliberate directional movement, while drag challenges require moving an object to its target. Hold challenges measure how long the input remains pressed.

Desktop controls

Most button-based challenges can be completed with a mouse or trackpad. Keyboard activation is supported for focused buttons where practical. Because some rounds depend on pointer movement or swipe direction, a mouse or trackpad may be required for those specific tasks.

Sound and visual feedback

Sound can be muted at any time using the sound control. Success and failure are also communicated visually, so sound is not the only form of feedback. The interface uses a high-contrast dark design and large interactive targets for the main game controls.

Pausing with the menu

Opening the site menu during a run pauses the current challenge. Closing the menu safely resumes that challenge instead of letting the timer continue in the background. This allows players to read help, policies or navigation options without losing a run unfairly.
